# TrendPulse – What's Actually Trending Right Now?

TrendPulse is a Python-based data analytics pipeline that collects, cleans, analyses, and visualizes trending stories from the Hacker News API.

The project demonstrates an end-to-end data workflow using Python, Pandas, NumPy, and Matplotlib.
